Cómo se evalúan las oportunidades

Con evidencia: un sitio propio, una función publicada o un contacto que aparece en una fuente enlazada. Pendiente: falta investigar; no equivale a ausencia.

Las sugerencias de servicio son hipótesis para conversar, no diagnósticos automáticos de fallas. Radar descarta sugerencias redundantes cuando la evidencia confirma que ya existe un menú, reservas o tienda digital. No se atribuyen puntuaciones de potencial comercial sin datos de ventas.

La búsqueda periódica desde GitHub podrá ampliar esta base cuando OpenStreetMap responda. Google Maps requiere credenciales y condiciones de uso independientes.
