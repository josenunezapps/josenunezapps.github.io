Política de Privacidad de Arven IDE

Última actualización: 20 de septiembre de 2026

Esta Política de Privacidad describe cómo Arven IDE, publicada por Zenix AR (José Núñez), trata la información durante el uso de la aplicación.

Resumen: Arven IDE está diseñada como un entorno de desarrollo para trabajar con proyectos Android desde el dispositivo. Los archivos del proyecto permanecen principalmente bajo control del usuario. La aplicación no requiere una cuenta propia de Arven IDE para sus funciones básicas.

1. Archivos y proyectos

Arven IDE puede crear, abrir, modificar, compilar y exportar proyectos y archivos de desarrollo seleccionados o creados por el usuario.

El contenido de esos proyectos —incluidos código fuente, recursos, configuraciones y archivos generados— se utiliza para prestar las funciones del entorno de desarrollo. Arven IDE no está diseñada para enviar automáticamente el contenido completo de los proyectos a servidores administrados por Zenix AR.

2. Almacenamiento local

La aplicación puede guardar localmente datos necesarios para su funcionamiento, como:

  • Proyectos recientes y rutas de archivos.
  • Preferencias del editor y de compilación.
  • Configuraciones internas del entorno.
  • Archivos temporales, cachés y resultados de compilación.
  • APK, AAB u otros artefactos generados por el usuario.
  • Información necesaria para restaurar el estado de trabajo.

Estos datos se conservan principalmente en el dispositivo hasta que el usuario los elimina, limpia los datos de la aplicación o desinstala Arven IDE.

3. Compilación y herramientas de desarrollo

Arven IDE puede utilizar herramientas locales de compilación, entornos Java, componentes del Android SDK y otros recursos técnicos necesarios para construir proyectos.

Algunas de estas herramientas o componentes pueden descargarse desde repositorios o servicios externos. En esos casos, se transmite la información técnica mínima necesaria para solicitar y descargar los archivos correspondientes, como ocurre en cualquier conexión de red estándar.

4. Acceso a Internet y servicios externos

Determinadas funciones pueden requerir conexión a Internet, por ejemplo para descargar dependencias, herramientas, SDK, componentes de compilación o acceder a repositorios remotos cuando el usuario decide utilizarlos.

Las solicitudes realizadas a servicios externos quedan sujetas también a las políticas de privacidad y condiciones del proveedor correspondiente.

5. Repositorios remotos y Git

Si el usuario configura o utiliza funciones relacionadas con Git o repositorios remotos, Arven IDE puede conectarse al proveedor elegido por el usuario para clonar, descargar, enviar o sincronizar contenido.

El tratamiento de datos realizado por GitHub, GitLab u otro proveedor externo depende de la configuración del usuario y de las políticas de dicho servicio. Zenix AR no controla las prácticas de privacidad de esos terceros.

6. Firma de aplicaciones

Arven IDE puede permitir generar y firmar paquetes de aplicaciones Android, incluidos archivos APK o AAB.

Cuando el usuario utiliza una clave de firma o un archivo keystore, esa información se utiliza para realizar la operación de firma solicitada. El usuario es responsable de proteger sus contraseñas, claves privadas y archivos de firma.

Arven IDE no necesita conocer el significado comercial o personal del contenido de esas claves para realizar la operación técnica de firma.

7. Credenciales y datos sensibles

No se recomienda guardar en proyectos contraseñas, tokens, claves API u otros secretos sin las medidas de protección adecuadas.

Si el usuario introduce credenciales para servicios externos, el uso de esas credenciales dependerá de la función activada y del proveedor correspondiente. El usuario debe revisar cuidadosamente qué datos incluye en sus proyectos y configuraciones.

8. Analítica, publicidad y cuentas

La versión actual de esta política no presupone la existencia de una cuenta propia de Arven IDE, publicidad personalizada ni un sistema propio de analítica de comportamiento.

Si en una versión futura se incorporan publicidad, telemetría, analítica, sincronización en la nube, cuentas de usuario u otros servicios que modifiquen el tratamiento de datos, esta política será actualizada para reflejarlo.

9. Compartición y venta de información

Zenix AR no vende ni alquila el código fuente, los proyectos o los archivos privados del usuario.

La información solo puede llegar a terceros cuando el usuario utiliza voluntariamente servicios externos —por ejemplo, repositorios remotos, gestores de dependencias o proveedores de descarga— o cuando el sistema Android realiza una acción expresamente iniciada por el usuario.

10. Conservación y eliminación

Los proyectos y archivos creados por el usuario permanecen en las ubicaciones donde hayan sido guardados. Eliminar Arven IDE no necesariamente elimina proyectos almacenados fuera del espacio privado de la aplicación.

Los datos internos de Arven IDE pueden eliminarse desde la configuración de Android o al desinstalar la aplicación.

11. Seguridad

Arven IDE procura trabajar con los archivos bajo control del usuario, pero la seguridad final de los proyectos, claves de firma y credenciales depende también de la seguridad del dispositivo, del sistema Android y de los servicios externos utilizados.

Se recomienda mantener el dispositivo actualizado, usar bloqueo de pantalla y conservar copias de seguridad seguras de los proyectos y claves de firma.

12. Privacidad de menores

Arven IDE es una herramienta de desarrollo de software y no está diseñada para recopilar deliberadamente datos personales de menores.

13. Cambios en esta política

Esta Política de Privacidad puede actualizarse cuando cambien las funciones de Arven IDE, los permisos solicitados, los componentes de terceros o las prácticas de tratamiento de datos. La fecha de la última actualización aparecerá al comienzo de esta página.
