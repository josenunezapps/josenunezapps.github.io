Política de Privacidad de Arven IDE

Última actualización: 29 de septiembre de 2026

Esta Política de Privacidad describe cómo Arven IDE, publicada por Zenix AR (José Núñez), trata la información durante el uso de la aplicación.

Resumen: Arven IDE está diseñada como un entorno de desarrollo para Android. El desarrollador de Arven IDE no recopila ni vende datos personales de los usuarios. Los proyectos, archivos y configuraciones permanecen principalmente bajo control del usuario en su dispositivo. Algunas funciones opcionales pueden conectarse directamente con servicios externos elegidos por el usuario, como GitHub.

1. Archivos y proyectos

Arven IDE puede crear, abrir, modificar, compilar, importar, exportar y administrar proyectos y archivos de desarrollo seleccionados o creados por el usuario.

El contenido de esos proyectos —incluidos código fuente, recursos, configuraciones y archivos generados— se utiliza para prestar las funciones del entorno de desarrollo. Arven IDE no envía automáticamente el contenido completo de los proyectos a servidores administrados por Zenix AR.

2. Almacenamiento local

La aplicación puede guardar localmente datos necesarios para su funcionamiento, como:

  • Proyectos recientes y rutas de archivos.
  • Preferencias del editor y de compilación.
  • Configuraciones internas del entorno.
  • Archivos temporales, cachés y resultados de compilación.
  • APK, AAB u otros artefactos generados por el usuario.
  • Información necesaria para restaurar el estado de trabajo.

Estos datos se conservan principalmente en el dispositivo hasta que el usuario los elimina, limpia los datos de la aplicación o desinstala Arven IDE.

3. Compilación y herramientas de desarrollo

Arven IDE puede utilizar herramientas locales de compilación, Java, componentes del Android SDK y otros recursos técnicos necesarios para construir proyectos.

Algunas herramientas, dependencias o componentes pueden descargarse desde repositorios o servicios externos. En esos casos se transmite únicamente la información técnica necesaria para solicitar y descargar los archivos correspondientes mediante conexiones estándar de Internet.

4. Acceso a Internet y servicios externos

Determinadas funciones pueden requerir conexión a Internet, por ejemplo para descargar dependencias, herramientas, SDK, componentes de compilación o para utilizar integraciones opcionales elegidas por el usuario.

Las solicitudes realizadas a servicios externos quedan sujetas también a las políticas de privacidad y condiciones del proveedor correspondiente.

5. Integración opcional con GitHub

Arven IDE incluye funciones opcionales para trabajar con GitHub. Si el usuario decide utilizarlas, puede proporcionar su nombre de usuario y un token de acceso personal de GitHub.

El token de GitHub se almacena cifrado localmente mediante Android Keystore y no se envía a servidores propios de Arven IDE.

Cuando el usuario inicia una acción concreta —por ejemplo verificar su cuenta, crear un repositorio, clonar, descargar, enviar o sincronizar contenido— Arven IDE se comunica directamente con GitHub. El tratamiento de esa información también está sujeto a las políticas y condiciones de GitHub.

6. Firma de aplicaciones

Arven IDE puede permitir generar y firmar paquetes de aplicaciones Android, incluidos archivos APK y AAB.

Cuando el usuario utiliza una clave de firma o un archivo keystore, esa información se utiliza para realizar la operación de firma solicitada. El usuario es responsable de proteger sus contraseñas, claves privadas y archivos de firma.

Arven IDE no envía automáticamente esas claves privadas o contraseñas a servidores administrados por Zenix AR.

7. Credenciales y datos sensibles

No se recomienda guardar en proyectos contraseñas, tokens, claves API u otros secretos sin las medidas de protección adecuadas.

Las credenciales utilizadas para servicios externos solo se emplean para las funciones que el usuario decide activar. El usuario debe revisar cuidadosamente qué datos incluye en sus proyectos y configuraciones.

8. Analítica, publicidad y seguimiento

La versión actual de Arven IDE no utiliza publicidad, analítica publicitaria, seguimiento de comportamiento ni vende información personal del usuario.

Arven IDE no requiere una cuenta propia para utilizar sus funciones básicas.

Si una versión futura incorpora publicidad, telemetría, analítica, sincronización en la nube, cuentas de usuario u otros servicios que modifiquen el tratamiento de datos, esta política será actualizada para reflejarlo.

9. Recopilación y compartición de datos

Zenix AR no recopila ni comparte con terceros los datos personales del usuario a través de servidores propios de Arven IDE.

Los datos pueden llegar a servicios externos únicamente cuando el usuario utiliza voluntariamente una función que requiere dicha transferencia, como GitHub o repositorios de dependencias y herramientas de desarrollo.

10. Conservación y eliminación

Los proyectos y archivos creados por el usuario permanecen en las ubicaciones donde hayan sido guardados. Eliminar Arven IDE no necesariamente elimina proyectos almacenados fuera del espacio privado de la aplicación.

Los datos internos de Arven IDE pueden eliminarse desde la configuración de Android o al desinstalar la aplicación. Las credenciales externas también pueden revocarse desde el servicio correspondiente, por ejemplo GitHub.

11. Seguridad

Arven IDE procura mantener los archivos bajo control del usuario y proteger credenciales sensibles mediante mecanismos del sistema Android cuando corresponde.

La seguridad final de los proyectos, claves de firma y credenciales depende también de la seguridad del dispositivo, del sistema Android y de los servicios externos utilizados. Se recomienda mantener el dispositivo actualizado, usar bloqueo de pantalla y conservar copias de seguridad seguras de proyectos y claves de firma.

12. Privacidad de menores

Arven IDE es una herramienta de desarrollo de software orientada a usuarios adultos y no está diseñada específicamente para menores de 18 años.

13. Cambios en esta política

Esta Política de Privacidad puede actualizarse cuando cambien las funciones de Arven IDE, los permisos solicitados, los componentes de terceros o las prácticas de tratamiento de datos. La fecha de la última actualización aparecerá al comienzo de esta página.
