ZENIX MVP LAB

Proyecto independiente de prueba.
NO modifica ni depende de zenix.com.ar.

Objetivo:
- validar una plantilla profesional reutilizable para negocios;
- separar contenido/configuración del diseño;
- permitir cambios rápidos de nombre, colores, productos, precios, promos y contacto;
- servir como base para el futuro flujo preview → revisión → producción.

Archivos:
- index.html
- styles.css
- config.js
- app.js

Para personalizar la demo, editar config.js.
